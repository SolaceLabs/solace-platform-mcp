# Solace Monitoring MCP Server (deprecated)

This server has been removed from this repository and is no longer maintained.

Use the **Solace Broker MCP Server** instead. It monitors and manages Solace event brokers through AI agents and is supported by Solace:

**https://github.com/SolaceProducts/solace-broker-mcp**

The Solace Broker MCP Server is a separate server with its own configuration, not a drop-in replacement. To use it with Solace Agent Mesh, see [Connect from Solace Agent Mesh](https://github.com/SolaceProducts/solace-broker-mcp#connect-from-solace-agent-mesh).

For all Solace MCP servers, see the [Solace Platform MCP Servers](../README.md) overview.
